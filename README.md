# Sequence-alignment-tool-implementing-Smith--Waterman-and-Needleman--Wunsch-matrices-BLOSUM62-
Python sequence-alignment tool implementing Needleman–Wunsch global and Smith–Waterman local alignment. It supports BLOSUM62, custom substitution matrices, affine gap penalties, traceback, score-matrix visualization, BioPython correctness validation, and runtime benchmarking in Google Colab.
